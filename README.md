# Transaction Anomaly & Data Integrity Audit Engine

An entry-level Information Systems auditing application built with Python, PostgreSQL, SQLAlchemy, Pandas, and Streamlit.

## Quick Start with Docker
1. Ensure Docker and Docker Compose are installed.
2. Run:
   ```bash
   docker compose up --build
   ```
3. Open your browser at:
   **http://localhost:8501**
